# Salat – Chrome extension

Manifest V3. Permissions: `alarms`, `notifications`, `storage`, `offscreen` (the last one only to play the optional chime). No host permissions, no geolocation, no network.

## How it works

- `background.js` is a service worker that Chrome suspends after ~30 s of idle. On install, startup, any settings change and once a day it computes the next 30 h of prayer times with `@salat/core` and creates one `chrome.alarms` entry per event. Alarms survive the worker being suspended and Chrome being restarted.
- When an alarm fires the worker wakes, shows one notification (with a **Snooze** button at prayer time) and, if enabled, plays a short chime through an offscreen document that closes itself afterwards.
- The popup shows today's times, the current prayer and a countdown. The options page saves as you type.
- The toolbar badge shows the next prayer's name as static text (can be turned off).

## Build

```sh
npm install            # from the repo root
npm run build -w chrome
```

Then open `chrome://extensions`, enable *Developer mode*, *Load unpacked* → `chrome/dist`.

`npm run zip -w chrome` produces the archive to upload to the Chrome Web Store.

## Notes

- Chrome extensions only run while Chrome is running; if Chrome is closed at prayer time there is no notification. Use the desktop app for that.
- The chime is a synthesized two-tone (generated by `tools/make_assets.py`), not an adhan recording — adhan recordings are usually copyrighted and would also be far too heavy for an extension.
